How a call works

You ask in Cursor or Grok Bot. The agent calls one aerospace tool with the values you gave, in the units that tool names. The program prints lines. Those lines are the result.

Rules

Pass only values you gave. If a tool says an input is missing, it will ask. Quote the printed lines. Do not invent a formula.

Sign-in

Google or Meta is the credential the plugin checks. The client id in the install snippet is shared. Your login is not. Linking a second provider, signing out, and deleting the account are on Account after you sign in.

Daily tool calls

Each tool call counts against a daily cap on your plan. After you sign in, Account shows how many you have used today and the cap for that plan.

Where it runs

The plugin endpoint is mcp.astraeus.de-wet.com/mcp. The install snippet fills that URL and the client id for you.
