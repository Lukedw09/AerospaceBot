Astraeus

Aerospace plugin for Cursor and Grok Bot

Checked formulas and small physics programs. The plugin runs them. The reply quotes the printed lines, instead of inventing an equation.

Install
Grok Bot aerospace

Output

A diagram, or a page you can move

The program prints the numbers. When it draws, it writes a PNG. When it builds a viewer, it writes one HTML file. Open that file and turn the view.

What it does

Ask in Cursor or Grok Bot for a density, a transfer, a shock, a section, a burn. Astraeus calls one tool with the values you gave. The program prints key: value lines, a PNG when it draws, and an HTML page when it builds a viewer. Those lines are the answer.

The client id in the install snippet is the same for everyone. Your Google or Meta login is the credential.
