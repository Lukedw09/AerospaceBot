What it does

Ask in Cursor or Grok Bot for a density, a transfer, a shock, a section, a burn. Astraeus calls one tool with the values you gave. The program prints key: value lines, and a plot when that program writes one. Those lines are the answer.

The client id in the install snippet is the same for everyone. Your Google or Meta login is the credential.
